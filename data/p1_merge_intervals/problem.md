# Merge intervals

Write `solve(intervals)` where `intervals` is a list of `[start, end]` pairs of
integers with `start <= end`, in any order.

Return a new list of non-overlapping intervals that covers exactly the same
points, sorted by start. Intervals that touch (`[1, 4]` and `[4, 5]`) are merged.
An empty input gives an empty list. Do not modify the input.
